學生學號：999900001（從登入頁「學生登入」輸入）。缺件情境預留未送出的暫存，學生登入後可接續填寫。

{% if judge_mode %}
  1. 正常完成：推進一天 → 執行本日流程 → 工作總覽放行 → 再執行 → 「模擬寄件匣」看附件4 確認信與委員個資索取 → 對確認信按「模擬收件人回信」寫「確認無誤」→ 執行 → 文件中心判讀。
  2. 學生缺件：推進一天 → 執行 → 模擬寄件匣看到補件通知 → 登出後以學號 999900001 登入補件 → 再登入{{ who }}帳號執行。
  3. 教授要求修改：走到附件4 寄出 → 在模擬寄件匣模擬教授回「可以，但口試日期請修改為 2026-11-15」→ 執行 → 「來信處理」頁核准或退回修正草稿 → 再執行，系統寄出新版確認信。
  4. 委員未回填：放行後執行 →「委員個資」頁取得委員專屬連結 → 開啟連結按「寄送驗證碼」→ 驗證碼在模擬寄件匣 → 回填。
  5. AI 協助判讀：推進一天 → 執行本日流程 → 工作總覽「AI 今日動態」與「AI 建議」頁看到兩筆建議：校外委員寫成簡稱的服務單位對應到距離表、「客座教授」的職稱判讀 → 採用服務單位對應後，案件的交通費才依距離表算出（採用前維持查無距離）。
