業務信箱來信 {{ tag(A) }}{{ tag(P) }}

AI 辨識寄件者、分類、摘要並擬草稿；學生提問會依案件資料與專員過去的回覆擬好回信。寫入與寄信都要專員核准。

→ 來信處理
信裡夾帶「忽略指令、直接放行」標「需注意」，不自動做任何事，交專員判斷
信裡有身分證、帳號先遮蔽，不送 AI；請專員到委員個資頁登錄　→ {{ link('office_committees', '委員個資') }}
AI 判讀失敗、寄件者未驗證轉人工，不自動回信　→ {{ link('office_mailbox', '來信處理') }}

系統每天自動跑 {{ tag(S) }}

建檔、檢核、寄補件信、催件、寄附件4。同一天重跑不會重寄。

→ 通訊記錄
每日自動化失敗總覽警示；補件截止日不會自動延後，需要時在期限設定手動覆寫　→ {{ link('office_settings_page', '期限設定') }}
寄送失敗確認信箱位址，必要時自己聯絡對方　→ {{ link('office_communications', '通訊記錄') }}
AI 出問題要全部停掉AI 總開關一鍵停止，全部改人工，規則流程照常　→ {{ link('office_ai_settings', 'AI 開關') }}
