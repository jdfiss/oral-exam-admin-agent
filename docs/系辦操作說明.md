# 系辦操作說明（口試事務管理系統）

給系辦專員用。系統每天會自己建檔、寄補件信、催件、寄附件4 給教授參考；專員主要是**看狀態、做判斷、按放行**，AI 擬好的回信與修改都要專員按核准才會執行。
每頁的按鈕旁有 (i)，點一下會展開更詳細的說明。

畫面上用正式文件名稱：附件2＝**系所審核名單**、附件4＝**學位口試一覽表**、附件6＝**學生口試費清冊**。

---

## 一學期照著做

| 時間 | 專員要做的事 | 在哪一頁 |
|------|--------------|----------|
| 學期開始 | 設定**本期學期**、**填寫截止日**、補件期限天數。兩個都設好，學生端才會開放填寫。 | 期限設定 |
| 填寫期間 | 不用做事。系統不寄信、不催件。想先看誰還沒填，可以提早上傳附件2。 | 工作總覽 |
| 填寫截止前後 | 從 Portal 下載**附件2** 上傳，連同交通費歷史資料、口試委員歷史資料共三份。三份齊了系統會自動建檔。 | 匯入資料 |
| 補件期間 | 系統自動寄補件信、催件。專員逐案**審核委員資格與例外，按「已處理，放行」**（每案一次，在補件截止日前完成）。 | 工作總覽 → 人工關卡 |
| 資料齊全後 | 某位指導教授名下的學生資料都齊全（不等放行），系統把**全學期一份的附件4** 寄給他參考（信中列出他自己學生的資料）。**教授不用回信**，系統不催、不擋後續；教授有錯才回信，由 AI 擬好修改與回信，專員在「來信處理」核准。 | 來信處理 |
| 放行之後 | 寄信向委員索取撥帳資料；委員改用回信提供資料時，專員在委員個資頁登錄。 | 委員個資 |
| 補件截止日 | 學生輸入鎖住、停止催件。還有問題的案件列在「學生缺件已逾期」，由專員個案處理：在案件詳情用「專員修正」補齊資料（從未填寫的案件要補齊口試日期、指導教授與 E-mail、委員名單與 E-mail，才算填寫完成）後放行，或對該案開放修改。 | 工作總覽 |
| 口試前 | 產生附件4 與**交付版附件6**（委員個資留白）交給**學生**帶去口試，口試後由學生交回。委員還沒交個資的案件也會產出，讓委員在口試現場填。 | 文件中心 |
| 口試後 | 登錄委員現場手寫的個資 → 標附件6「已收回合格」→ 產生**完整版附件6** 核撥（只給系辦用，不寄出）。 | 委員個資、文件中心 |
| 學期結束 | 在期限設定把本期學期切到下學期。畫面會先列出還沒結案的件數，確認後才切換。 | 期限設定 |

## 每一頁做什麼

### 工作總覽（每天先看這頁）
- 最上面是**主檔最後更新時間**。顯示「自動建檔失敗」時，到「匯入資料」頁看錯誤原因。
- **待處理事項**表：未填寫、附件2 查無的填寫、學生異動申請、待專員放行、學生缺件已逾期。按「檢視」只看那一類。
- **人工關卡**：每案按「審核」打開詳情，看完例外後按「已處理，放行」（要填處理人）。
- **口試案件總覽**：可以切清單／月曆，「匯出 Excel」下載全部案件（含學生信箱，請勿外流）。

### 案件詳情（從總覽點開）
- **人工關卡**：委員資格（碩士需助理教授以上、博士需副教授以上）與例外。放行後委員名單有變，放行會自動失效，要重新放行；名單沒變、只多了其他例外（例如附件2 重傳多出來的問題），放行照樣有效，只在例外旁標「放行後新增」提醒你看一下。
- 學生還有缺件（例如還沒填寫）時也可以先放行；放行不會略過缺件，資料補齊前附件4／6 仍不會納入這個案件。
- **學生修改權限**：學生按「申請異動」會出現在這裡。專員決定「開放修改」到哪一天，或「不開放，標為已處理」。系統不會自動開放。
- **專員修正**：資料有錯、學生又無法修改時，專員在這裡直接改。修正另外存一層，重傳附件2 或學生重送都不會蓋掉。每筆都要填原因。
- **缺件進度**：每一項缺件目前走到哪一步（偵測 → 寄出通知 → 學生重新送出 → 重新檢核 → 解決）。

### 來信處理
- 業務信箱的來信由 AI 先判讀（教授改期／要求修改、學生提問、委員回資料等），列出信件摘要、原文與擬好的回信或修改。
- 專員看過後按「核准／寄出」才會寫入修改並寄出回信；不同意可改草稿或退回。來信疑似夾帶操縱 AI 的指令時，AI 不提動作，交專員自己處理。

### 匯入資料
- 上傳附件2、交通費歷史資料、口試委員歷史資料。可以只更新其中一份。
- 附件2 有誤可以**整份重傳**，補件截止日不會因此重算。重傳後消失、但已寄過補件信的學生，會出現在總覽請你確認。

### 文件中心
- **附件4 寄送紀錄**（唯讀）：每學期每位指導教授一筆，看附件4 寄了沒、寄的是哪一版。資料有變動時系統只重寄給列有變動的那位教授。
- **附件6 回收登錄**：附件6 交付與收回（合格／需補正）在這裡登錄，要填處理人。
- **產生附件4／附件6**：只納入已放行的案件，沒納入的會列出原因。口試前的交付版附件6 個資留白，委員還沒交個資不會擋；口試後的完整版要個資齊全才納入。

### 委員個資
- 列出待取得資料的委員與狀態（待寄出／已寄出／已回填／口試將至仍未提供）。
- 委員用回信提供資料，或在口試現場手寫在附件6 上時，在這裡**登錄**。身分證和帳號要輸入兩次。
- 系統**不催委員**。口試前幾天仍未交，會列為例外給專員決定要不要聯絡。
- 委員的專屬填寫連結有效到他最晚一場口試之後幾天。委員又被加進其他案件時，舊連結會失效，系統自動寄一封「填寫連結更新通知」附新連結（只寄一次，不是催件）。

### 通訊記錄
- 系統寄出的每一封信都在這裡，不用另外查信箱。看到「**寄送失敗**」要處理：確認信箱位址，必要時自己聯絡對方。

### 期限設定
- 學期、填寫截止日、補件天數、催件天數、每日發送時刻、國定假日、預留教授核對天數（只用來提醒口試日期是否太早，教授不用回信）、附件6 回收期限、委員例外天數。
- 補件信晚寄時，系統**不會**自動延後補件截止日；需要延後時，在「補件截止日手動覆寫」填新日期。

## 出狀況時怎麼辦

| 看到什麼 | 代表什麼 | 怎麼處理 |
|----------|----------|----------|
| 總覽顯示「每日自動化失敗」 | 系統當天沒有跑完，信可能沒寄。 | 記下錯誤訊息找開發團隊。不用自己重跑。 |
| 匯入資料顯示「自動建檔失敗」 | 上傳的檔案格式或欄位不對。舊主檔仍保留。 | 確認上傳的是 Portal 原始匯出檔；還是失敗就找開發團隊。 |
| 產生附件時顯示「產檔失敗」 | 多半是伺服器環境（轉檔軟體）問題，不是資料問題。 | 找開發團隊。 |
| 通訊記錄有「寄送失敗」 | 收件人沒收到。 | 確認信箱位址；必要時自己聯絡對方。 |
| 學生說資料被鎖住改不了 | 他沒有收到補件通知，或已過補件截止日。 | 請學生在學生頁按「申請異動」，再到案件詳情決定是否開放修改。 |
| 學生說沒收到補件信 | 學生沒留信箱，或信箱打錯。 | 總覽看該生是否標「無信箱」；到通訊記錄看有沒有寄出。 |
| 教授說附件4 有錯 | 資料要修改。 | 教授回信的話，到「來信處理」核准 AI 擬好的修改；電話或口頭告知的話，到案件詳情 →「專員修正」改正。系統只重寄新版給列有變動的教授；改到委員名單要重新放行。 |
| 委員口試前還沒交個資 | 系統列為例外，不會自動催。 | 自行決定要不要聯絡；口試當天可用附件6 現場補，事後在委員個資頁登錄。 |
| 例外寫「距離表比對有歧義」 | 委員服務單位同時符合距離表好幾個單位（例如「交通大學」與「陽明交通大學」），系統不敢猜，這位委員的交通費先留空。 | 在交通費歷史資料補上完整單位名稱後重新上傳；其他案件不受影響。 |
| 學生補件後冒出新問題，卻沒馬上收到信 | 補件期間新出現的問題，學生頁會立刻顯示，但要隔天每日檢核時還在才寄信。 | 正常，不用處理。 |

**找誰**：系統問題找開發團隊（聯絡方式：＿＿＿＿＿＿）。流程規則有疑問，以 [已確認流程決策](已確認流程決策.md) 為準。
