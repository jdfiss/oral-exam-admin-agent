## 試用步驟

1. 系辦登入 →「期限設定」：本期學期填 `1141`，填寫截止日填一週後，學生信箱後備格式填 `{學號}@cc.example.edu`，儲存。
2. 學生登入 `999900001`、`999900003`，照上表填寫送出。`999900002` 不登入。
3. 系辦 →「匯入資料」：上傳三份示範檔，看到「自動建檔成功，3 案」。
4. 「工作總覽」：應看到 1 件尚未填寫、3 件待專員放行。
5. 補件期間的信件要等每日自動化執行才會寄出。試用時請開發者手動執行一次（或把填寫截止日設成昨天，再執行 `python -m koushi automate`，不加 `--send` 只預覽）。
6. 人工關卡逐案按「審核」→ 填處理人 →「已處理，放行」。張小英那案請看例外說明。
7. 「委員個資」頁：看到林小芳、張志明的索取狀態，試著登錄一筆回覆（身分證可用 `A123456789` 以外的任一合法格式假號碼）。
8. 「通訊記錄」頁：每封寄出的信都在這裡。

試用時請記下：哪裡看不懂、按錯、找不到，回報給開發團隊。
